# M-1000 Maxigun HMG Mobile v3.2.0

## Highlights

- Replaces the M-1000 Maxigun projectile with the E/MG-101 HMG Emplacement projectile.
- Enables firing while moving.
- In-game verification confirms the projectile fields and movement flag were applied.
- Includes the optional read-only projectile probe and an English installation guide.

## Projectile changes

- Damage / durable damage: 80 / 18 → 200 / 40
- Armor penetration: AP3 → AP4
- Caliber: 8.0 mm → 12.5 mm
- Mass: 11 g → 52 g
- Velocity: 920 m/s → 880 m/s

## Compatibility and installation

- Game build: 25480438 / executable 1.8.46015.0
- Requires Bingus Shared Loader v15 or later with addon support enabled.
- Disable other Maxigun mods, especially `starm/minigun_backpack_heavy_mobile`, to avoid conflicts.
- See [the installation guide](installation-guide.md) for setup, verification, troubleshooting, and the probe.

The mod checks the `game.dll` SHA-256 and refuses to run if the game binary differs. Runtime memory modification may violate the game's Terms of Service and carries anti-cheat risk. Use at your own risk.
